# Changelog

## 1.0.0 — Initial public release

- Adds a persistent HUD reminder while a delivered corpse is still waiting in the native delivery area.
- Adds a native-style bell cue and stock-style popup when the first confession becomes available.
- Adds a persistent prayer indicator until no confession remains available.
- Preserves the game's normal donkey arrival trigger, sound and visual treatment.
- Keeps corpse/confession transient popups readable for the same two real-time seconds during sleep or accelerated meditation.
- Uses native game state only; no Keeper's Alerts save data or gameplay-mechanics changes.
